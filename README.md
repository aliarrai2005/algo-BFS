# Parcours en largeur (BFS) d'un arbre binaire

Implémentation en C++ du parcours en largeur sur un arbre binaire, à l'aide d'une file (`std::queue`).

## Fichiers
- `arbre.h` : classe `Noeud` et fonction `parcoursLargeur`
- `main.cpp` : construction d'un arbre de 12 nœuds et appel du parcours
- `rapport_bfs_arbre.tex` : rapport LaTeX

## Compilation et exécution
```bash
g++ main.cpp -o bfs
./bfs
```

## Résultat
```
Parcours en largeur : 7 9 67 1 28 8 10 29 2 57 40 6
```
